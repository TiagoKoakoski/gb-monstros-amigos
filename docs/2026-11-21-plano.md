# Monstros Amigos (Game Boy) — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gerar por script um projeto GB Studio 4.3.2 do "Monstros Amigos" (jardim, 4 monstros, entregar itens encostando, vaga-lume guia, festa), compilar para ROM e web, e provar o comportamento rodando a ROM num emulador.

**Architecture:** Dois scripts Python geram tudo: `gerar_arte.py` desenha os PNGs em 4 tons; `gerar_projeto.py` copia o template `blank` do GB Studio e escreve cena, atores, gatilhos, variáveis e eventos como arquivos `.gbsres` (JSON) com IDs determinísticos. `compilar.sh` chama a CLI do GB Studio (compilada do fonte v4.3.2). Os testes rodam a ROM no PyBoy, apertam botões e leem as variáveis do jogo na memória.

**Tech Stack:** GB Studio 4.3.2 (CLI em `~/Projetos/jogos/_ferramentas/gb-studio/out/cli/gb-studio-cli.js`, Node 21.7.1 em `~/Projetos/jogos/_ferramentas/node21/`), Python 3 + Pillow + PyBoy (venv `~/Projetos/jogos/_ferramentas/venv`), pytest.

**Spec:** `docs/2026-11-21-design.md`

## Global Constraints

- Nenhum texto necessário para jogar (nada de `EVENT_TEXT`, `EVENT_CHOICE`, menus).
- Sem inimigos, sem tempo-limite, sem game over, sem susto (nada de tremer câmera forte, sons ásperos).
- Arte e som 100% próprios: PNGs gerados por `gerar_arte.py`; som só com os efeitos sintetizados do motor (`EVENT_SOUND_PLAY_EFFECT` tipo `beep`/`tone`). Nenhum arquivo dos templates `gbs2`/`gbhtml` além do `blank`.
- Cenário (background): só as 4 cores `#E0F8CF`, `#86C06C`, `#306850`, `#071821` (claro → escuro). Sprites: transparente = `#65FF00` + 3 cores `#E0F8CF`, `#86C06C`, `#071821` (o mesmo padrão dos sprites de exemplo do GB Studio 4.3.2; sprite de Game Boy tem 3 cores visíveis).
- Cena top-down (`TOPDOWN`), jardim 40x36 tiles (2x2 telas), câmera segue o jogador.
- Pegar e entregar acontece só por encostar (gatilhos), nenhum botão obrigatório.
- Carrega um item por vez. Item ao monstro errado: nada se perde, monstro faz "não" (emote + balanço).
- Vaga-lume aparece após ~5 s sem progresso e voa até o próximo objetivo.
- 4 ajudados → festa; qualquer botão recomeça do zero.

## Review Focus

1. Criança segurando direcional contra parede/monstro na diagonal → nunca fica presa; 1 tile livre em volta de todo monstro e item (teste `test_sem_bloqueio_em_volta` na Task 3).
2. Já carregando um item e encostar em outro item → nada muda (não troca, não some) (teste `test_segundo_item_ignorado` na Task 4).
3. Entregar de novo a um monstro já ajudado / encostar nele sem item → nada quebra, contador não muda (teste `test_monstro_ajudado_ignora` na Task 4).
4. Recomeçar → itens reaparecem, balões voltam, variáveis zeradas (teste `test_recomeco_limpo` na Task 6).
5. Vaga-lume durante a festa ou várias vezes empilhado → não aparece na festa e nunca há mais de um (teste `test_vagalume_unico_e_fora_da_festa` na Task 5).
